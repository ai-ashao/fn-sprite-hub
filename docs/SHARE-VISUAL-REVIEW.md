# FN Sprite Hub — Share Artifact Review Scorecard

Use this after the artwork review/upgrade pass, not before it.

## Review preview

Review the original 1080px-wide PNG at its natural dynamic height and a 360px-wide scaled preview.

## Required fixtures

1. My Collection
2. Missing 6
3. Missing 24
4. Missing All
5. Unmastered 12
6. Mastered 8
7. Celebration Collection
8. Celebration Mastered

`Missing All` must be generated from the current released dataset, not a hard-coded count.

## Technical hard gate

Every fixture must have:

- no stretched artwork
- no clipped required text
- no text overlap
- no broken or remote artwork
- exactly one complete poster
- visible FN Sprite Hub signature
- readable Finish badge at 360px preview width
- preview content matching the downloaded PNG
